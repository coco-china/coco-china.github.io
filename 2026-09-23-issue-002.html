NEW KNOWLEDGE

今日新知：流程图——算法的藏宝图

传说在古代，英雄们出门冒险前都要先看一张藏宝图：先去哪儿、遇到岔路怎么选、最后抵达宝藏。算法就像藏宝图，而流程图就是把这张图画出来。

算法就是解决一件事的分步骤方法。做一道菜、整理书包、上学路线……都是算法。流程图用约定好的图形把这些步骤画出来，让人一眼看懂。

流程图四大常见符号：
🔵 圆角矩形 = 开始 / 结束
🔷 平行四边形 = 输入 / 输出
💠 菱形 = 判断（会分出「是 / 否」两条路）
⬜ 矩形 = 处理 / 做一件事
➡️ 箭头 = 流程方向

思辰，流程图的魅力就是：把想不清楚的事情画清楚。等以后学 Scratch 或 Python，你写的程序也是这样一条一条执行的。

CHALLENGE

练习挑战

先自己走一遍流程，再对照答案。错了也没关系，告诉我就行～

⭐
第 1 题 · 入门
流程图中，表示「判断 / 分支」的符号是什么形状？
▾查看答案与解析
✅ 答案
菱形 ◇
💡 解题思路
圆角矩形表示开始 / 结束 平行四边形表示输入 / 输出 矩形表示处理步骤 菱形专门用来表示「判断」，答案通常是「是 / 否」或「对 / 错」
记住它：菱形的四个角像十字路口，正好要我们选择走哪条路！
⭐
第 2 题 · 入门
看上面的「带外套」流程图，如果今天温度是 18℃，流程会输出什么决定？
▾查看答案与解析
✅ 答案
不用带外套
💡 解题思路
判断条件是：温度 < 15℃？ 18℃ 不小于 15℃，所以走「否」那条路 「否」对应的结果是：不用带外套
18℃ 其实体感可能还凉，但在这个流程图里它按规则走～算法就是严格按规则执行的小助手。
⭐⭐
第 3 题 · 进阶
把下面「早上起床」的步骤按合理顺序编号：
A. 起床穿衣
B. 刷牙洗脸
C. 吃早饭
D. 背书包出门
▾查看答案与解析
✅ 答案
A → B → C → D
💡 解题思路
流程图要按时间顺序执行 先起床，才能洗漱 洗漱完再吃早饭 吃完早饭才出门上学
如果顺序错了，比如先出门再起床……就会变成《西游记》里的妖怪了吧？🐒
⭐⭐⭐
第 4 题 · 挑战
一个流程图判断一个数是否为偶数：输入 ÷ 2，如果余数为 0 就输出「偶数」，否则输出「奇数」。输入 17，会输出什么？
▾查看答案与解析
✅ 答案
奇数
💡 解题思路
17 ÷ 2 = 8 余 1 判断条件：余数是否为 0？ 1 ≠ 0，所以走「否」分支 输出「奇数」
这个判断是编程里超级常用的「if...else」！以后会写成：如果余数==0，就是偶数，否则就是奇数。
⭐⭐⭐⭐
第 5 题 · 大挑战
试着用文字描述一个判断「考试成绩是否及格」的流程图。及格线是 60 分，输入一个分数 75，它会输出什么？如果输入 55 呢？
▾查看答案与解析
✅ 答案
75 分 → 及格；55 分 → 不及格
💡 解题思路
开始 → 输入分数 判断：分数 ≥ 60？ 如果是，输出「及格」 如果否，输出「不及格」 结束
下次考试，你可以给自己画一个「奖励流程图」：及格 → 奖励一颗星；全对 → 奖励三颗星！⭐
CONNECTION

思维连接

流程图不只是编程的工具，它是一种「把步骤想清楚」的能力：

📐 数学连接
解应用题时，我们也在按步骤走：读题 → 找条件 → 列算式 → 检查。流程图让这四步清晰可见，不容易跳步漏条件。
♟ 围棋连接
围棋里也有一串「如果……就……」的决策：如果对手断我，我就连接；如果我被包围，我就做活。高手脑子里就像装着很多张流程图！
